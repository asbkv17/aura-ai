# AURA AI — Adaptive User Recovery & Activity

AI-powered wellness assistant website (AI Conference 2026).

## Состав проекта

| Файл / папка | Что это |
|---|---|
| `index.html` | Весь сайт: главная, AI Assistant, Health Library, My Progress, Fitness & Recovery, Daily Wellness, About, Privacy & Safety |
| `api/ask.js` | Серверная функция: принимает вопрос с сайта и отправляет его в Google Gemini. Ключ хранится только здесь, на сервере |
| `api/_library.json` | Тексты статей библиотеки, на которые опирается ИИ |
| `favicon.png`, `apple-touch-icon.png`, `og-image.png` | Иконка сайта и картинка-превью для ссылок |
| `vercel.json` | Настройки безопасности для Vercel |
| `.env.example` | Пример переменных окружения (сам ключ сюда **не** вписывать) |

## Как выложить на Vercel (≈10 минут)

1. **GitHub.** Войдите на github.com → **New repository** → имя `aura-ai` → **Create repository**.
   На странице репозитория нажмите **uploading an existing file** и перетащите **всё содержимое** папки `aura-ai`
   (включая папку `api`) → **Commit changes**.
2. **Vercel.** Войдите на vercel.com через GitHub → **Add New… → Project** → выберите `aura-ai` → **Import**.
3. На экране настройки откройте **Environment Variables** и добавьте:
   - Name: `GEMINI_API_KEY`
   - Value: ваш ключ из Google AI Studio (начинается на `AQ.` или `AIza`)
4. Нажмите **Deploy**. Через минуту появится ссылка вида `aura-ai.vercel.app`.
5. Откройте сайт → **AI Assistant**. В углу чата должно быть написано **Live AI · Gemini**.

> Если ключ добавили уже после первого деплоя: **Settings → Environment Variables** → добавить ключ →
> **Deployments → … → Redeploy**. Переменные применяются только после нового деплоя.

## Как это работает

- Сайт спрашивает у `/api/ask`, подключён ли ключ. Если да — чат работает в режиме **Live AI · Gemini**.
- На вопрос сайт находит подходящие статьи библиотеки и отправляет их вместе с вопросом на сервер.
  Сервер добавляет правила безопасности и отправляет всё в Gemini.
- Срочные темы (боль в груди, мысли о самоповреждении) обрабатываются сразу на сайте, без ИИ,
  с рекомендацией звонить в экстренные службы.
- Если ключ не работает, закончилась квота или Gemini недоступен, ассистент **не ломается**:
  отвечает из библиотеки и показывает пометку.
- Защита от злоупотреблений: не больше 20 вопросов от одного посетителя за 10 минут.

## Необязательные настройки (Environment Variables)

| Переменная | Зачем |
|---|---|
| `GEMINI_MODEL` | Принудительно выбрать модель, например `gemini-3.5-flash-lite`. По умолчанию сервер сам пробует `gemini-3.5-flash-lite` → `gemini-3.1-flash-lite` → `gemini-3.6-flash` → `gemini-2.5-flash` |
| `RATE_LIMIT` | Сколько вопросов можно задать с одного адреса за 10 минут (по умолчанию 20) |

## Если что-то не работает

- **В чате «Library mode» вместо «Live AI · Gemini»** — ключ не добавлен или не сделан Redeploy.
- **Ответы с пометкой «The live AI is unavailable right now»** — откройте в Vercel **Project → Logs**:
  - `Gemini error 401/403` — ключ не принят: создайте новый в AI Studio и замените.
  - `Gemini error 429` — закончилась бесплатная квота (подождите или подключите оплату в AI Studio).

## Безопасность ключа

Ключ хранится только в настройках Vercel и никогда не попадает в браузер посетителя.
Не вставляйте ключ в `index.html` и не загружайте файл `.env` на GitHub.
